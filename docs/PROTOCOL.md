# Протокол Raspberry Pi ⇄ ESP32

UART 115200 8N1 (Pi: GPIO14/15 → `/dev/serial0`; ESP32: GPIO16/17). Тот же протокол идёт по USB ESP32 — можно управлять с ноутбука из монитора порта.

## Кадр

```
$ТЕЛО*CS\n
```
`ТЕЛО` — поля через запятую, `CS` — XOR всех байтов тела, две hex-цифры. Пример: `$PNG,1*44`.
Для ручной отладки ESP32 принимает строку и без `*CS` (`$PNG,1`), но кадр с неверной суммой отбрасывает (`NAK,-,CHECKSUM`).

## Команды Pi → ESP32

Второе поле — номер команды `seq`. ESP32 отвечает `ACK,seq` (принято) или `NAK,seq,ПРИЧИНА`; когда действие закончено — `DONE,seq,РЕЗУЛЬТАТ,пояснение`. Если ACK потерялся, Pi повторяет кадр с тем же `seq` — ESP32 только подтверждает снова, действие не перезапускается.

| Команда | Пример | Что делает |
|---|---|---|
| `HB` | `$HB*0A` | heartbeat, раз в 200 мс. Нет кадров > 1 с во время движения → остановка, `DONE …,LINK` |
| `PNG,seq` | | проверка связи, `DONE,seq,OK,версия` |
| `DRV,seq,м[,м/с[,курс°]]` | `DRV,7,2.5,0.25,90.0` | проехать 2,5 м (минус — назад), держа абсолютный курс 90° |
| `TRN,seq,°[,°/с[,1]]` | `TRN,8,90,45` / `TRN,8,180,45,1` | повернуть на угол (плюс — налево) / до абсолютного курса, если 5-е поле = 1 |
| `VEL,seq,м/с,°/с` | `VEL,9,0.2,0` | ручное управление; надо повторять чаще 0,6 с |
| `STP,seq` | | остановиться; текущая команда завершается `ABORT` |
| `BLD,seq,0/1` | | отвал вверх / вниз |
| `CAL,seq` | | калибровка гироскопа 2 с (робот должен стоять) |
| `RST,seq` | | обнулить x, y, курс |
| `SET,seq,ключ,значение` | `SET,10,obst_stop,40` | изменить параметр (ключи — `Robot::applySet`) |

Причины NAK: `BUSY` (уже едет), `BADARG`, `UNKNOWN`, `LOWBAT`, `BUMPER`, `CHECKSUM`, `FORMAT`.
Результаты DONE: `OK`, `BLOCKED` (препятствие не ушло за 15 с), `STALL` (застрял), `BUMPER`, `ABORT`, `LOWBAT`, `LINK`, `FAIL`.

## ESP32 → Pi

`TEL,t_мс,x,y,курс,vЛ,vП,СОСТОЯНИЕ,дальн_Л,дальн_Ц,дальн_П,Vакб,отвал,флаги` — 10 раз в секунду.
Состояния: `IDLE DRIVE TURN VEL CALIB FAULT`. Флаги: 1 — пауза из-за препятствия, 2 — бампер, 4 — АКБ разряжается, 8 — АКБ критично, 16 — отказ гироскопа, 32 — потеря связи.

`EVT,имя,…` — события: `BOOT`, `CAL,OK|FAIL,смещение,шум`, `OBST,см`, `CLEAR`, `STALL,сторона`, `BUMP`, `LOWBAT,В`, `CRITBAT,В`, `LINK_LOST`, `GYRO_FAIL`.

Строки симулятора, начинающиеся с `#` (`#TRUE,t,x,y,курс` — истинное положение), Pi пропускает.
